# 風の迷宮

ブラウザで動く、完全オリジナルのソロ・ターン制ローグライク。

## v5
- 30Fの通常迷宮をクリアすると50Fの深層迷宮を解放
- 50Fをクリアすると99Fの奈落迷宮を解放
- 10階ごとにステージテーマ・色味・ボスが変化
- ボスは赤い予兆付きの攻略型大技。30Fボスは第二形態あり
- モンスターハウス突入時に赤サイレン・画面揺れ・振動演出
- 特殊フロア：暗闇 / 罠密集 / 宝物庫 / 休憩 / 水路
- 毒 / 眠り / 混乱 / 鈍足 / 封印の状態異常と対策アイテム
- 武器・盾に強化値、低確率で特殊能力付きレア装備
- 精鋭モンスターとレアドロップ
- 「使う / 装備 / 投げる / 置く」を実装。投擲は上下左右6マス
- 死亡・クリア時に到達階、討伐数、投擲数、罠、装備などを振り返り表示
- 敵の単発ダメージに上限を設け、一撃死になりにくい設計
- 4方向移動・4方向攻撃。斜め操作なし
- スマホは方向キー長押しで連続移動、文字選択・長押しメニューを抑制
- スマホ画面は盤面中心の1画面レイアウト
- ミニマップ / 視界 / ログ / 中断セーブ / 発見記録
- PWA対応（オフラインキャッシュ）

## 操作
- PC: 矢印キー / WASD で移動・攻撃
- I: 持ち物
- M: 魔物録
- Space: 待つ
- スマホ: 方向キーをタップで1歩、長押しで連続移動
- 投げる選択中は方向キーで投擲、中央ボタンでキャンセル

## 起動
静的ファイルだけなので、HTTPサーバーで開けば動きます。

```bash
python -m http.server 8000
```

## Render
