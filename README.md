# 風の迷宮

ブラウザで動く、完全オリジナルのソロ・ターン制ローグライク。

## 現在の実装
- 30階構成 / 毎階ランダム生成
- 1アクション=1ターン
- 8種の敵AI
- HP / レベル / 経験値 / 力 / 満腹度
- 武器・盾・草・食料・札・壺
- 4種の罠
- ミニマップ / 視界 / メッセージログ
- 中断セーブ / 自動セーブ
- 図鑑用の発見記録 / 最深到達 / クリア回数
- PCキーボード / スマホボタン / スワイプ操作
- Web Audioの簡易SE
- PWA対応（オフラインキャッシュ）

## 起動
静的ファイルだけなので、HTTPサーバーで開けば動きます。

```bash
python -m http.server 8000
```

## Render
Static Siteで公開可能です。
- Build command: 空欄または `echo build`
- Publish directory: `.`
